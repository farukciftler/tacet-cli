The conditional frame

04-document — recapture recommended

The summary text is missing diacritics in three words. The cause is that the demo PDF was written in ASCII — Tacet summarised the document faithfully, so this is not an application bug. But nobody browsing the Turkish store will know that difference; it reads as a typo.

A second defect: the prompt says Summarise this document in three bullets, while the reply is a flat paragraph. The instruction was visibly not carried out.

No code change is needed: recapturing the frame with a demo PDF whose spelling is correct ends the problem. Until then, do not put it in the first three, or drop it from the set — six frames is enough.

The pending frame

07-connections — the sentence was fixed, the frame is still old

Sitting inside the framing, fully legible, was this sentence: Unless you connect, ‹OLD BRAND› does not go online. (Tacet/Views/ConnectionBoard.swift)

The sentence was absolute and wrong. Connections (MCP) and web search are two independent surfaces: even with no MCP server connected, if the user has turned web search on the app goes online. A global property was being claimed from a local panel.

The sentence has been fixed in the code: the panel now says Connect your own MCP server and Tacet can use its tools. Until you do, this surface stays closed. So there is no longer a copy obstacle to this frame returning to the set — the one remaining obstacle is that the frame (like the whole set) was captured with the old brand. On recapture, 07 goes back into the set. The frame is valuable: it was the only one showing the "off by default, you are the one who turns it on" promise on a single screen. Detail: screenshots/pending/READ-DO-NOT-UPLOAD.txt
