# Code of conduct

Short version: **be someone people want to work with.**

This is a small project. There is no committee and no process, so this file is a
statement of intent rather than a procedure.

## What is expected

* Assume the other person is trying to do the right thing.
* Argue with the work, not the person. "This measurement does not support that
  claim" is the most useful sentence in this repository; "you don't understand
  this" is not.
* Say what you measured. Disagreements here are usually settled by running
  something, and the person who runs it is right until someone runs a better one.
* English is not everyone's first language, and this project is bilingual by
  design. Do not mistake an awkward sentence for an awkward idea.

## What is not

Harassment, personal attacks, discrimination, or sustained disruption of
someone's work. Publishing someone's private information. Sexualised language or
imagery. Deliberately wasting a maintainer's time.

## Reporting

Email <hello@abdullahfaruk.com>, or open a private security advisory if you would
rather not use email. Reports are read by the maintainer and by nobody else.

The available responses are: a private word, deletion of the content, and a
block. That is the whole range — with a project this size, honesty about what can
be enforced is worth more than borrowed procedure.

## Scope

Issues, pull requests, discussions, commit messages, and anywhere someone is
representing this project.
